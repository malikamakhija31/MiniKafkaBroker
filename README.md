# MiniKafkaBroker

A lightweight Kafka-inspired message broker built with Python, FastAPI, and React.

## Features
- Topic and partition management
- Message publishing and consumption
- Consumer group management
- Multi-broker cluster support
- Real-time event monitoring using WebSockets
- React-based monitoring dashboard

## Tech Stack
- **Backend:** Python, FastAPI
- **Frontend:** React, Vite, JavaScript, CSS
- **Communication:** REST API, WebSocket

## Project Structure
- `backend/` – Broker services, storage, APIs and cluster management
- `frontend/` – React dashboard and user interface

## Getting Started
Refer to the backend and frontend folders for installation and run instructions.

## Purpose
To demonstrate the core concepts of a distributed messaging system through a lightweight broker implementation and real-time dashboard.
